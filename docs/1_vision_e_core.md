# Visione e nucleo

Sito vetrina statico di Pikobit (https://pikobit.it): presenta i servizi di sviluppo software, siti web e app
e le pagine dedicate alle città servite, con un blog tecnico in italiano.

## Obiettivi
- Farsi trovare per le ricerche di zona (una parola chiave per pagina, vedi [SEO.md](SEO.md)).
- Pagine veloci, accessibili, senza dipendenze esterne a runtime (font e script serviti dal sito).
- Contenuti veri: niente promesse o numeri non verificati.

## Nucleo
- HTML, CSS e JavaScript vanilla; nessun backend, nessun database.
- Meta SEO e dati strutturati generati da script idempotenti.
- Blog: articoli nuovi aggiunti da una pipeline settimanale automatica (fuori da questo repo).

## Fuori ambito
- Applicazioni web dinamiche, account utente, e-commerce.
